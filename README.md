# ExpressEat

# 📦 API de Sistema de Delivery

Esta é uma API RESTful desenvolvida com **TypeScript**, **Express** e **MongoDB** para gerenciar um sistema de delivery. O sistema permite o cadastro e gerenciamento de usuários, restaurantes, pedidos, entre outras funcionalidades típicas de um aplicativo de entrega.

---

## 🚀 Tecnologias Utilizadas

- [Node.js](https://nodejs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Express](https://expressjs.com/)
- [MongoDB](https://www.mongodb.com/)
- [Mongoose](https://mongoosejs.com/) (ODM)
- [Dotenv](https://github.com/motdotla/dotenv) para variáveis de ambiente

---

## 📁 Estrutura de Pastas

src/

├── controllers/ # Controladores (lógica das rotas)

├── models/ # Modelos do MongoDB (schemas)

├── routes/ # Rotas da aplicação

├── middlewares/ # Middlewares personalizados

├── repositories/ # Lógica de negócio (opcional)

├── types/ # Tipagens auxiliares
